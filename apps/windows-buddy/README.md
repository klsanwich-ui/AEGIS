# Talk Buddy (Windows Talk MVP)

เพื่อนบนหน้าจอแบบกดปุ่มลัดแล้วถาม — **ไม่ใช่แอป heyclicky.com** และยัง**ไม่มี Agent**

กดปุ่มลัด → ถ่ายหน้าจอเฉพาะตอนนั้น → พิมพ์คำถามภาษาไทย → โมเดลตอบ + อ่านเสียง + ชี้จุดบนจอ  
ไม่มีไมค์ก็ใช้ได้ ความฉลาดมาจาก OpenAI ที่คุณใส่คีย์เอง จ่ายตามครั้งที่ใช้

## ความต้องการ

- Windows 10/11 (พัฒนาด้วย Electron จึงรันบนเครื่องที่มี GUI ได้ รวม Linux/macOS สำหรับทดสอบ UI)
- Node.js 20+
- [OpenAI API key](https://platform.openai.com/api-keys) สำหรับภาพ + TTS (และ Whisper ถ้าเปิดไมค์)

## สิทธิ์บน Windows

- **Screen capture** — Windows อาจถามตอนถ่ายจอครั้งแรก (Settings → Privacy → Screen capture / Graphics)
- **Microphone** — ต้องอนุญาตเฉพาะเมื่อเปิดไมค์ในตั้งค่า ไม่บังคับ
- ปุ่มลัดค่าเริ่มต้น: `Ctrl+Alt+Space` (บน Mac เป็น `Command+Alt+Space`)

## รันจากซอร์ส

```bat
cd apps\windows-buddy
npm install
npm start
```

แอปไปอยู่ที่ถาดระบบ (system tray) ไม่โชว์ไอคอนหลักในแถบงาน

1. คลิกไอคอนถาด → ตั้งค่า → ใส่ `sk-...`
2. โมเดลแนะนำ `gpt-4o-mini` เพื่อประหยัด
3. กด `Ctrl+Alt+Space` แล้วพิมพ์คำถามเกี่ยวกับสิ่งบนจอ
4. ถ้าโมเดลใส่ `[POINT:x,y:ป้าย]` จุดเหลืองจะบินไปพิกัดนั้น (x,y เป็นเปอร์เซ็นต์ของจอที่ถ่าย 0–100)

คีย์เก็บที่ `%APPDATA%\windows-talk-buddy\settings.json` ไม่ส่งไปเซิร์ฟเวอร์ของโปรเจกต์นี้

## ตัวเลือกไมค์

ค่าเริ่มต้นปิดไมค์ พิมพ์อย่างเดียว  
ถ้ามีไมค์: ตั้งค่า → เปิดไมค์ → ในกล่องถามกด «พูดแทนพิมพ์» ใช้ Whisper ถอดภาษาไทย

ถ้า TTS ของ OpenAI ไม่สำเร็จ จะลองเสียงในระบบ (`th-TH`) แทน

## ค่าใช้จ่าย

หนึ่งคำถาม = หนึ่งรอบโมเดล (ไม่วน agent)  
มีค่า API ตามผู้ให้บริการ โดยเฉพาะภาพหน้าจอ TTS ถูกกว่ามาก
